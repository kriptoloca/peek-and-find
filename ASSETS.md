# ASSETS.md — Art & audio list (v1.1)

Style: flat vector, cute but not childish, bold silhouettes, 2–3 tone shading, 0–2 px outlines, saturated palette per theme. No text, no brands, no recognizable characters. Not AI-looking. Not "made for kids" (no nursery pastels, no baby faces).

## Source rules
- **Source format must be SVG** (layered fills, no embedded rasters). This is non-negotiable: color variants are generated from the SVG at build time. A pack that ships only flattened PNGs is rejected.
- Buy ONE consistent pack (itch.io / GraphicRiver / Creative Market, $20–60) covering most families; fill gaps with Kenney (CC0, kenney.nl, SVG available) only if the style matches. Record license + purchase proof in `assets/LICENSES.md`.
- Shipped: PNG frames in a texture atlas (free-tex-packer-cli or TexturePacker), max 2048×2048 per theme, trimmed, 2 px padding. Rendered at 512 px longest side for base frames.
- Naming: `theme_family_variant.png` → `kitchen_mug_a.png`. Baked color variants: `kitchen_mug_a_c1.png`, `kitchen_mug_a_c2.png`. Odd-variant: `kitchen_mug_odd.png`. Family icon for prompts: `kitchen_mug_icon.png` (clean, centered, same silhouette as variant a).

## Recolor pipeline (`scripts/recolor.mjs`)
Runs on the SVG sources before atlas packing:
- For each base frame produce 2 color variants by rotating the hue of the main fills by +25° (`_c1`) and −25° (`_c2`), keeping outlines, highlights and shadows unchanged. Fills to recolor are marked by class `fill-main` in the SVG (or by the palette list in `data/themes.ts` if the pack has no classes).
- Odd One Out and Spot 5 use the same frames; nothing is recolored at runtime.
- Output is deterministic (same SVG → byte-identical PNG) so atlases are reproducible.

## Per theme (5 themes × 40 base sprites)
Each theme: 12 families × 3 variants (36) + 4 extra singletons (40). With 2 color variants per family frame the atlas holds 36 × 3 + 4 + 12 icons = 124 frames, which fits 2048² at 512 px source scaled to ~256 px in-atlas.
Families must include confusable pairs (same tag).

**Kitchen** — mug, pan, spoon, apple, egg, bread, cheese, teapot, cup, bottle, bowl, knife(blunt, cartoon) · singletons: toaster, kettle, plant, clock
**Beach** — crab, shell, starfish, ball, bucket, fish, ice cream, flip-flop, umbrella (small), sunglasses, coconut, bottle · singletons: towel, surfboard, seagull, sandcastle
**City Street** — car, dog, cat, bike, pigeon, cone, mailbox, balloon, hat, bag, lamp, trash can · singletons: bench, hydrant, scooter, sign (blank)
**Forest** — mushroom, acorn, fox, owl, rabbit, leaf, berry, log, flower, butterfly, snail, pinecone · singletons: tent, campfire (no flame animation needed), backpack, stone
**Space** — planet, star, rocket, alien, satellite, moon, comet, helmet, robot, crystal, ufo, asteroid · singletons: telescope, flag (blank), capsule, lander

Tags per family (for decoys): `round` (apple, egg, ball, coconut, planet, moon, acorn, berry), `animal` (crab, fish, dog, cat, pigeon, fox, owl, rabbit, snail, alien), `tall` (bottle, teapot, lamp, rocket, tree), `flippable` (all asymmetric sprites).

## Backgrounds (5)
1080×1080 PNG for Find/Odd and a 1080×840 crop for Spot 5 (same image, center crop, generated by script). Low contrast, ≤ 200 KB each, simple shapes, no small details that compete with objects. Every object must keep luminance contrast against it: ≥ 35 % of a sprite's area at ≥ 3:1 (WCAG) against the background mean, enforced by `npm run assets` (docs/visual-review.md). Plus 2–4 large props per theme (table, sand dune, road, bush, nebula) as separate sprites.

## UI (shared atlas)
Icons: play, daily, check, streak-flame, heart (full/empty), star (full/empty), hint-bulb, home (back to Title), sound on/off, music on/off, "≠" (odd), "⟷5" (spot), continue-play, retry, close. Buttons: 2 rounded shapes (9-slice). Confetti: 3 small shapes. Logo: Pebblit mark + "Peek & Find" wordmark (the only text asset).

## Audio (CC0 from Kenney Audio / freesound, trimmed, OGG + M4A fallback for Safari)
15 SFX files: tap_correct_1/2/3 (pitch variants), tap_wrong, pop, sparkle, scene_complete, star_1/2/3, heart_lose, hint_reveal, button, confetti, daily_complete. One music loop ≤ 150 KB, 20–30 s, mellow. Total audio ≤ 1 MB.

## Budget
Per theme atlas ≤ 2.5 MB (color variants roughly double the frame count) · UI atlas ≤ 400 KB · backgrounds ≤ 1.2 MB · audio ≤ 1 MB · code ≤ 1.5 MB (Phaser ≈ 1.2 MB) → initial load ≈ 5–6 MB, target ≤ 8 MB (boot loads UI + first theme + its background only; other themes load from the bundle on preload, never from the network).

## Store assets (for Playgama submission)
- Icon 512×512, square, no text.
- Thumbnail 1280×720 and 1080×1080: single scene, one obvious target circled, optional one word ("FIND?").
- 3 screenshots per aspect (9:16, 16:9).
- 15 s gameplay video, no voice, no text.
