# Brand marks (generated: `npm run brand`, source `scripts/brand.mjs`)

Design philosophy: `philosophy.md` ("Field & Signal"). Fonts: `assets/brand/fonts` (Outfit and
Bricolage Grotesque, SIL Open Font License, licence texts beside them). Everything is drawn as
SVG and rendered with sharp, so a change to a colour or a form is one edit and one run.

| File | Use |
| --- | --- |
| `peek-and-find-icon-1024.png` | app icon, full bleed (platforms mask their own corners) |
| `peek-and-find-icon-1024-rounded.png` | the same with rounded corners and transparent outside |
| `peek-and-find-icon-512.png` | the 512 icon of ASSETS.md / the store |
| `peek-and-find-icon.svg` | vector source of the icon (no fonts needed) |
| `peek-and-find-wordmark-dark.png` / `-transparent.png` | horizontal logo, 1600×480 |
| `pebblit-profile-1024.png` | studio profile photo, square (safe for a circle crop) |
| `pebblit-profile-circle-1024.png` | the same, already cropped to a circle (transparent outside) |
| `pebblit-mark.svg` | vector source of the studio mark |
| `pebblit-wordmark-dark.png` / `-transparent.png` | studio logo with the mark, 1600×480 |
| `brand-sheet.png` | preview at 256 / 128 / 64 px |

Palette: night `#1b1f2a`, sand `#f4f1de`, accent `#ffc857` (the hint ring of the game), signal
teal `#2ba193`, slate `#566590`, eight muted field tones. The accent is used once per mark.
